# global-fix-application

Active once a fix has been routed. The fix is canonical; deviations from it are tracked as deviations, not as improvements. Local adaptations are legitimate only after the canonical fix has been observed to fail in the specific environment, and the adaptation is itself documented as a candidate addition to the Atlas.

This capability is part of the WFGY 4.0 — Problem Map & Governance skill set. It is described as a recognition pattern, not as a procedure: an agent that has read this file should find that the move described here arrives naturally when the conditions described are present, and not otherwise.
